# typescript-aws-dashboard

Rust GraphQL backend and TypeScript frontend project.

## Setup

```bash
nix develop
make setup
```

## Development

Start backend server:

```bash
make dev-backend
```

GraphiQL IDE: http://localhost:8080

Start frontend development server:

```bash
make dev
```

## Build

```bash
make build
```

## Test

```bash
make test
```

## Format

```bash
make fmt
```

## Lint

```bash
make lint
```
